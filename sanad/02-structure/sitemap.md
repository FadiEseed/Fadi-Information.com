## B. لوحة الزبون (بعد الدخول — Dhru Client Area بثيمنا)

| الصفحة | المحتوى |
|---|---|
| الرئيسية (Dashboard) | الرصيد بخط كبير · زر «اشحن» · آخر 5 طلبات بحالتها · إعلانات (خدمة جديدة / توقف خدمة) · زر واتساب الدعم |
| طلب جديد | بحث خدمة ← تعبئة الحقول ← تأكيد السعر ← تنفيذ. طلبات IMEI بالجملة (Bulk) |
| طلباتي | فلترة حسب الحالة: قيد التنفيذ / تم / مرفوض · نسخ الكود بضغطة · إعادة الطلب |
| شحن الرصيد | اختيار طريقة الدفع ← المبلغ ← تعليمات + رفع الإثبات ← حالة الطلب |
| كشف الحساب | كل حركة: شحن، خصم، استرجاع، مع الرصيد بعد كل حركة |
| الفواتير | فواتير الشحن قابلة للتحميل |
| التذاكر | فتح تذكرة مربوطة برقم الطلب |
| الإعدادات | بيانات المحل · 2FA · مفتاح API · قائمة IP المسموحة · إشعارات (إيميل / واتساب) |

## C. لوحة الإدارة (Dhru Admin — لفادي)
- اعتماد الشحنات اليدوية (أهم شاشة يومياً)
- الموردين: Iraq Server (أساسي) + مورد احتياطي مع Failover
- قواعد الربح لكل قسم ولكل مجموعة زبائن
- مراقبة الطلبات العالقة (> وقت التسليم المعلن)
- الموظفين والصلاحيات (لما يكبر الشغل)

---

## D. رحلة الزبون الجديد (الـ Funnel)
1. يشوف Reel أو بوست ← يعلّق كلمة مفتاحية أو يدخل الموقع
2. يسجل حساب (أقل من دقيقة)
3. رسالة ترحيب واتساب تلقائية: «أهلاً بمحل X، أنا فادي من سَنَد…» + رابط طرق الدفع
4. أول شحنة ← بونص أول شحنة (يتحدد بالمرحلة 5)
5. أول طلب ناجح ← متابعة شخصية: «وصلك الكود؟»
6. بعد 3 طلبات ← عرض الانتقال لمستوى Reseller
