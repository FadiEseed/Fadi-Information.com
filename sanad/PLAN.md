## تنبيه تجاري
بالعالم العربي إحنا بننافس Iraq Server نفسه على نفس الزبون وبسعر أعلى. يعني لازم نربح بـ:
1. دعم فني عربي سريع على الواتساب.
2. واجهة أنظف وأسهل من كل السيرفرات.
3. كتالوج منتقى (مش 5000 خدمة)، مع شرح ووقت تسليم حقيقي لكل خدمة.
4. مورد ثاني يخلي هامشنا على الكريدت المشهور صغير بس موجود.
5. وكلاء شحن بكل دولة (المرحلة 7) بيستلموا دفع محلي وبيشحنوا رصيد.

## أسئلة Iraq Server (للإرسال)
1. لما أربط منصتي الخاصة معكم عبر API، شو سعر الـ API عندي؟ وشو صيغة الـ API (Dhru-compatible؟) ووين التوثيق؟ وهل في مستويات أسعار حسب حجم الشغل؟
2. في رسوم شهرية أو نسبة غير فرق السعر؟
3. شو سياسة الاسترجاع للطلبات الفاشلة؟ هل بيرجع الرصيد تلقائياً عبر الـ API، وكم بياخد وقت؟
4. هل بتشوفوا بيانات زبائني (أسماء، أرقام، IMEI) أو بتتواصلوا معهم بأي شكل؟
5. هل في مانع إني أربط موردين ثانيين بنفس اللوحة؟
6. لما تتغير أسعاركم أو توقف خدمة، كيف بتبلغوني؟ وهل الـ API بيحدث الأسعار تلقائياً؟
7. شو مدة الدعم الفني إلي كموزع، وعلى أي قناة؟
